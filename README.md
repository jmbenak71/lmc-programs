# Lake Michigan College Programs by Area

Degree and certificate pages for Lake Michigan College's Career & Workforce Education Division, organized by department and program area.

**Live site:** https://jmbenak71.github.io/lmc-programs/

## What's here

- `index.html`: the program finder (search, degree/certificate filter, departments and program areas)
- `programs/`: one web page per program
- `pdf/`: the printable two-page program sheet for each program

## How to update

These files are generated by the **LMC CIS Program Sheet Builder** artifact on claude.ai. Program content is edited there, not here.

1. Open the builder and click **View website**, then **Download site** (leave "Include a printable PDF" ticked).
2. Unzip the download and replace `index.html`, `programs/` and `pdf/` in this repository with the new copies. Deleting the old `programs/` and `pdf/` folders first removes pages for programs that were dropped.
3. Commit and push. GitHub Pages republishes within a minute or two.
